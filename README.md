# Road Guard

Lightweight driving assistant for speed-limit and traffic-camera alerts.

## Initial scope

- Ho Chi Minh City
- Binh Duong
- Vung Tau
- Foreground GPS tracking
- Current-speed display
- Speed-limit alerts
- Traffic/speed-camera alerts
- Designed to run on a second phone alongside Google Maps

Development happens on feature branches and is merged into `main` through pull requests.
